# Personality by KLIK

Print-ready files for the shop: PDF → print JPGs with bleed, photo bleed, merging, page tools and the Imposer (press sheets, booklets, yearbook signatures, covers — PDF and InDesign).

## Download

**[Get the latest version](https://github.com/jeymsx/klik-releases/releases/latest)** — download `Personality-by-KLIK-Setup-….exe` and run it.

**Install:** download **Personality-by-KLIK-Setup-….exe** below and run it. Windows may say
"Windows protected your PC" (the app isn't code-signed) — click **More info → Run anyway**. It installs for you only,
no admin rights needed, and adds Personality by KLIK to the Start menu.

**Already installed?** The app tells you when there's a new version (… menu → Check for updates) and updates itself.
Your settings, presets and recent jobs are kept.

**No installer?** The portable zip works too: extract it and open the .exe inside.
